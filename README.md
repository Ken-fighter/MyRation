# 🍲 MyRation - 个人食材库存配给系统

基于"剩余顿数"的动态库存管理与"乱炖"风味推荐系统。

## ✨ 功能特点

- 📦 **智能入库**：批量输入食材，支持克(g)和个数(个)两种单位
- 🍳 **弹性乱炖算法**：4品类/5品类选择，自动配给食材
- 🛒 **买菜建议**：根据计划顿数生成购买清单
- 💾 **本地存储**：数据保存在浏览器中，不会丢失

## 🚀 快速开始

### 在线使用
直接访问部署好的网址即可使用。

### 本地运行
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 📱 添加到手机主屏幕

1. 用手机浏览器打开网址
2. 点击"分享"按钮
3. 选择"添加到主屏幕"
4. 像APP一样使用！

## 🧮 核心算法

### 配给公式
```
单品建议量 = 库存 × (1 - 损耗系数) / 剩余顿数
```

### 选品优先级
1. **强制位**：已切开或剩余≤1顿的必须入选
2. **核心位**：确保1种肉类 + 1种叶菜
3. **填充位**：根据CP库搭配
4. **弹性控制**：5品类时从耐放食材增补
